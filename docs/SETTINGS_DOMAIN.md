# SETTINGS_DOMAIN

## Objetivo

Centralizar la configuración operativa sin exponer detalles técnicos al usuario final.

## Capas

1. Default de plataforma
2. Ajuste de empresa
3. Ajuste de centro de trabajo
4. Override de empleado

## Bloques funcionales

- control horario;
- planificación;
- turnos;
- centros de trabajo;
- calendarios;
- ausencias;
- notificaciones;
- seguridad;
- auditoría.

## Principios

- los ajustes deben ser condicionales;
- no mostrar opciones irrelevantes;
- guardar cambios explícitamente;
- versionar políticas para preservar jornadas ya iniciadas.
